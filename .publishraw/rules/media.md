# media

Keep new images local until actual version-specific approval. Read approved encoding mode and source identity through owning validators. The pinned helper owns credentials, upload/status and exact asset receipts; expose only redacted results. Substitute only verified final URLs for the same approved images using qualified source spans. Other content/image/mode changes require renewed approval. Item replacement/deletion retains public assets. Public asset deletion requires its separate explicit approval. Missing media support is a blocker for new media, independent of text and existing references.
